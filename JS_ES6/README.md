### let and const

**Definition:** let and const are JavaScript keywords used to declare block-scoped variables. let allows reassignment, while const does not allow reassignment.

```
    let age = 23;
age = 24; // Allowed

const name = "Rifat";
// name = "Rahim"; // TypeError
```
